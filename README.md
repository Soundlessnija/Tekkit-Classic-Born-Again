# Tekkit Classic Born Again

Official issue tracker for the Tekkit Classic: Born Again modpack.

## Reporting a Bug

Please use the Issues tab to report problems with the modpack.

When reporting a bug, please include:

- Modpack version
- What you were doing when the problem occurred
- Whether it happens in a new world
- Crash report, if one was generated
- `latest.log` when applicable

Please do not report issues directly to individual mod authors until we've determined that the problem is caused by that mod rather than the modpack or a compatibility issue.
